# Progress

## Shipped

**Sep 2026: the retro loop.** Learnings from each working session go into the repo file that governs that work, get committed, and load in the next session. The trigger is manual: the agent lists candidate lessons at the end of a run and the person decides whether to write them back.

**4 Oct 2026: writing skill v1.0.** Three open-source anti-slop skills merged into one catalogue of 36 tells in 8 families, with write, edit, detect, suggest and retro modes and a 50-point score. A first test run with five agents exercising every mode produced v1.0.1 the same day.

**5 Oct 2026: comment replies and personal style.** The comment reply skill shipped. The writing skill learned the person's own posting style (casing, punctuation, list shape) from real samples, and a new rule: a comment on someone else's post is about their post.

**15 to 17 Oct 2026: carousel director.** A design library of 18 layouts and 14 colourways (32 designs), a director agent that picks the most valuable carousels from a source, a fact audit against the transcript, and an independent reviewer agent. A separate design-taste skill was retired and its anti-AI design rules folded into the carousel skill, so one skill owns carousels.

**23 Oct 2026: writing skill v1.1.2.** Eight releases in 19 days, each from a real correction (a casual line that read as childish, a polished DM that read as AI, acronyms that must stay in capitals).

**25 Oct 2026: podcast hook skill.** Built from a study of 18 two-person interview episodes: how each one opens, where its bites come from, when money is first mentioned, when the brand ident lands, and how those choices track with performance. A blind re-check of 55 classifications agreed 96% with the first pass.
